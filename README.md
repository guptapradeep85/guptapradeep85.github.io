# Dr. Pradeep Gupta Academic Portfolio

Static GitHub Pages portfolio for Dr. Pradeep Gupta, AI researcher, Assistant Professor at AKGEC Ghaziabad, and Postdoctoral Research Fellow at NKUST Taiwan.

## Technologies

- HTML5
- CSS3 with responsive layout, glassmorphism, dark/light theme variables, and reduced-motion support
- Vanilla JavaScript for canvas visuals, publication filtering/search, counters, navigation state, theme persistence, and subtle 3D tilt
- No backend and no paid APIs

## Structure

```text
/
├── index.html
├── assets/
│   ├── css/styles.css
│   ├── js/main.js
│   ├── cv/Pradeep_Gupta_CV_2026.pdf
│   ├── icons/favicon.svg
│   └── images/og-preview.svg
├── robots.txt
├── sitemap.xml
└── README.md
```

## Local Development

Run a static server from the repository root:

```bash
python -m http.server 8080
```

Then open `http://127.0.0.1:8080/`.

## Deployment

This repository is designed for GitHub Pages. Push changes to the configured Pages branch and GitHub Pages will serve the static files.

## Updating Content

Use the latest verified CV as the source of truth. Do not invent publication metadata, identifiers, links, dates, citations, impact factors, h-index values, awards, grants, patents, or affiliations.
